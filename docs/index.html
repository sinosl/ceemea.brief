How this brief is made

Each morning a Python pipeline pulls headlines (Google News RSS), IMF World Economic Outlook forecasts, BIS policy rates, FX rates, 10-year government bond yields (US Treasury, OECD) and inflation by component (OECD) for ten CEEMEA sovereigns and six global drivers. Country deep dives add annual World Bank data on economic structure, labour markets, trade and remittances, computed directly with no language model. Headlines are ranked for bond relevance by a transparent keyword model. Changes since the previous brief (rate moves, FX moves over 1%, IMF revisions) are computed directly from the data. A language model then writes each country summary using only those numbered sources, and must cite a source for every bullet. Before publishing, every figure in the text is checked against the cited source; anything that does not match is flagged ⚑ rather than removed.
